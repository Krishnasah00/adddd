Drawer

Reusable side / top / bottom drawer.

Component overview

General-purpose side panel for filters, detail views and quick-create forms.

Original functionality (from the archive)

  • Left, right, top and bottom drawers (24rem sides, 70vh / max 420px top and bottom)
  • Fade-in backdrop and panel (the original declares slide-in names but only applies fade-in)
  • Title header with close button, scrolling body, optional footer
  • Escape and backdrop dismissal, body scroll lock, role=dialog + aria-modal

Dashboard adaptations / additions

  • Promise-style closed, close reasons, Tab focus trap and focus restoration enhancement
  • Custom width/height, declarative data-drawer-open templates enhancement
  • Short exit fade, no re-entrancy issues when stacked with Modal (shared scroll-lock counter) enhancement

Known limitations

  • The original has no nested-drawer or resize support; stacking works but is not designed or styled specially

Drawer Preview

Uses the real drawer component. Nothing opens until you click a button.

Every variant opens on the side you choose. Form and filter drawers use the Forms component; the delete action asks AppAlert and reports through the toast system.

Drawer Usage Examples

Open a drawer from JavaScript
const drawer = AppDrawer.open({
  side: "right",            // left | right | top | bottom
  title: "Filters",
  body: document.querySelector("#filter-form"),   // Node, array of Nodes, or plain text
  footer: [
    { label: "Cancel" },
    { label: "Apply", variant: "primary", onClick: () => applyFilters() }
  ],
  closeOnBackdrop: true,
  closeOnEscape: true,
  onClose: reason => console.log("closed:", reason)
});

drawer.close();            // close programmatically
await drawer.closed;       // resolves with the close reason
Declarative HTML (no JavaScript to write)
<button type="button" data-drawer-open="#filters-drawer">Filters</button>

<template id="filters-drawer" data-side="right" data-title="Filters" data-width="420px">
  <div data-slot="body"> ...fields... </div>
  <div data-slot="footer">
    <button class="btn" data-drawer-close>Cancel</button>
    <button class="btn btn-primary" data-drawer-close>Apply</button>
  </div>
</template>
Form drawer with validation (Forms component)
AppDrawer.open({
  title: "Quick create user",
  body: formElement,   // <form id="user-form" data-ff-form> ... </form>
  footer: [{ label: "Create", variant: "primary", closes: false, onClick: () => formElement.requestSubmit() }]
});

document.addEventListener("appform:valid", e => {
  if (e.target.id === "user-form") { toast.success("User created."); AppDrawer.closeAll(); }
});

Styling and theme

Colours, border, radius, typography and reduced motion come from the dashboard tokens in theme.css, so Light/Dark/System, accent, radius and the animation toggles apply automatically. z-index is 300 (AppAlert 1000, toast 9999).

Laravel notes

Plain JS, no routes. In Blade, keep drawer bodies as <template> partials and open them with data-drawer-open; load content from your own endpoint inside onOpen if needed.
