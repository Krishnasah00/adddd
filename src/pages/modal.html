Modal

Reusable generic modal dialog.

Component overview

Generic dialog for forms, previews and custom content.

Original functionality (from the archive)

  • Sizes sm, md, lg, xl and full-screen
  • Title, description, close button, scrolling body, footer, loading spinner
  • Escape and backdrop close, scroll lock, panel focus on open, role=dialog + aria-modal

Dashboard adaptations / additions

  • Tab focus trap and focus restoration enhancement
  • Declarative data-modal-open templates, close reasons, closed promise enhancement
  • Options to disable backdrop/Escape closing enhancement

Known limitations

  • No nested-modal visual stacking beyond layering order
  • The original used a shared AppLoader; this port uses a small built-in spinner

Modal Usage Examples

Open and close
const modal = AppModal.open({
  title: "Edit profile",
  description: "Update your details.",
  size: "md",                 // sm | md | lg | xl | full
  body: "Plain text, or pass a Node / array of Nodes",
  footer: [
    { label: "Cancel" },                                  // closes by default
    { label: "Save", variant: "primary", onClick: modal => save() }
  ]
});

modal.close();
const reason = await modal.closed;   // button | backdrop | escape | api
Custom content and buttons
const content = document.createElement("div");
content.innerHTML = "<p>Any markup you build safely</p>";

AppModal.open({
  title: "Custom",
  body: content,
  footer: [
    { label: "Delete", variant: "danger", closes: false, onClick: async modal => {
        const r = await AppAlert.fire({ icon: "warning", title: "Are you sure?", showCancelButton: true });
        if (r.isConfirmed) modal.close();
    } }
  ]
});
Form inside a modal, handle success
const form = document.querySelector("#user-form-template").content.cloneNode(true);
const modal = AppModal.open({
  title: "Add user",
  body: form,
  footer: [{ label: "Create", variant: "primary", closes: false,
             onClick: () => document.getElementById("user-form").requestSubmit() }]
});

document.addEventListener("appform:valid", e => {
  if (e.target.id === "user-form") { toast.success("User created."); modal.close(); }
});
Loading state
const modal = AppModal.open({ title: "Loading", loading: true });
fetch("/your-endpoint").then(r => r.text()).then(html => { modal.setLoading(false); modal.setBody(html); });

Separation from AppAlert

AppModal is a generic container (forms, previews, custom content). AppAlert remains the alert and destructive-confirmation system; the two are independent and AppAlert (z-index 1000) opens above a modal (300).

Laravel notes

Keep modal bodies as Blade partials rendered into <template> tags, or fetch HTML from a route and pass it to setBody().
