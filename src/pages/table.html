Table

Reusable data table with search, sorting, pagination, selection, export and import.

Component overview

Primary reusable data table for AdminKit; Users, Products, Orders, Roles & permissions and the server-side example all use the same engine with different configuration.

Original functionality (from the archive)

  • Sortable headers, individual column filters, filter chips, pagination with page-size selector, row selection with select-all and a bulk-actions bar
  • Column visibility menu, column resizing and reordering, sticky header and columns, expandable rows, floating row menus
  • Loading skeleton, error with retry, empty and no-results states
  • CSV and Excel export, print, CSV import with validation, server-side mode

Dashboard adaptations / additions

  • Compact variant matching the reference Users design: Users (87) heading, icon toolbar, filter row, detail rows, bulk bar, chevron pager enhancement
  • Typed column filters (text / select / number expressions / date range) that combine enhancement
  • setState(), reload(), clearFilters(), AppTable.details() and icon row actions enhancement

Known limitations

  • Select-all selects the current page only
  • Number filters use the expression syntax (no separate min / max inputs); date filters need native date inputs
  • Only one sticky data column (left) plus the actions column (right) is supported

Table Usage Examples

Users table (compact variant, expandable rows, bulk + row actions)
const table = AppTable.create(document.getElementById("users"), {
  variant: "compact",          // reference design: page size in the toolbar, icon buttons, replace-style bulk bar
  title: "Users", showCount: true,     // renders "Users (87)" from the real record count
  data: rows, getRowId: r => r.id,
  selectable: true, maxHeight: "520px",
  columns: [
    { id: "name",   header: "Name",   filter: { type: "text", placeholder: "Search Name..." } },
    { id: "email",  header: "Email",  filter: "text" },
    { id: "role",   header: "Role",   filter: "text" },
    { id: "status", header: "Status", filter: { type: "select", options: ["active", "inactive", "pending"] },
      render: (row, v) => AppTable.badge(v, v === "active" ? "ok" : v === "pending" ? "warn" : "neutral") },
    { id: "orders", header: "Orders", type: "number", filter: { type: "number" } },   // ">100", "<=20", "10-50"
    { id: "joined", header: "Joined", type: "date",   filter: { type: "date" } }      // from / to
  ],
  expandable: r => AppTable.details([
    { value: r.orders, label: "lifetime orders" }, { value: r.joined, label: "joined" },
    { value: r.role, label: "role" }, { value: r.email, label: "email" }
  ]),
  rowActionsVariant: "compact",
  rowActions: [
    { label: "View",   icon: "eye",    onClick: row => openDetails(row) },
    { label: "Edit",   icon: "pencil", onClick: row => openEditModal(row) },
    { label: "Delete", icon: "trash",  danger: true, onClick: row => confirmDelete(row) }
  ],
  bulkActions: [
    { label: "Delete",      icon: "trash", danger: true, onClick: (rows, table) => deleteMany(rows) },
    { label: "Assign role", icon: "users", onClick: (rows, table) => assignRole(rows) }
  ],
  toolbar: { export: ["csv", "xls"], print: true, import: { expectedHeaders: ["name", "email", "role"], onImport: rows => saveImport(rows) } }
});

Table states
table.setState("loading");                 // skeleton rows
table.setState("error", "Could not load users.");   // message + Retry (calls config.onRetry)
table.setState("empty");                   // "No records available" (data is kept)
table.setState("normal");                  // back to the data
// "No results" (with a Clear filters button) appears automatically when filters match nothing.
Server-side mode (backend-agnostic onQuery)
const table = AppTable.create(host, {
  serverSide: true,
  variant: "compact", title: "Users", showCount: true,
  columns: [ /* same column and filter definitions */ ],
  onQuery: q => {
    // q = {
    //   page: 2, pageSize: 10, search: "priya",
    //   columnSearch: { name: "pri", role: "Admin", orders: ">100", joined: "2023-01-01..2023-06-30" },   // individual filters
    //   sortField: "joined", sortDirection: "desc",        // also available as q.sort = { id, dir }
    //   filters: { }                                       // toolbar select filters (legacy)
    // }
    table.setLoading(true);
    yourDataProvider(q)                       // fetch, XHR, jQuery AJAX... your choice
      .then(res => table.setData(res.data, res.total))
      .catch(() => table.setError("Could not load users."));
  },
  onRetry: () => table.reload()               // re-issues onQuery with the current state
});

// Expected response: { "data": [ { ... }, ... ], "total": 87 }

rowActions, rowActionsVariantmenu (⋯), icons (text buttons) or compact (icon-only with tooltip and aria-label; icon: eye, pencil, trash, check, users...)
filters[], toolbarLegacy toolbar select filters; toolbar: { search, columns, pageSize, export:["csv","xls"], print, import }

setState(name), reload(), clearFilters()Instance methods: normal / loading / error / empty states, re-issue the last query, reset all filters

Theme and Laravel notes

Uses card, border, accent, radius and density tokens; badges reuse .badge ok|warn|bad|info|neutral. The engine contains no backend code, no routes and no sample data: pass rows from @json($rows) or an API resource, or use server-side mode and map onQuery to paginate(), orderBy and your filter scopes. Sample data and simulated server live only in table-demo.js.
